# COURTSIDE 화면 구성

Spring Boot 정적 리소스로 제공하는 로컬 농구 분석 UI입니다. 별도의 프런트엔드 빌드 도구나 외부 CDN 없이 동작하며, 각 메뉴는 독립 HTML 페이지로 이동합니다.

최종 정리일은 2026-11-27입니다. 프로젝트 범위와 로컬 API 진행 상황은 [프로젝트 현황](project-status.md), 외부 API 조사 결과는 [KBL API 데이터 정리](kbl-api-data.md)를 참고합니다.

## 메뉴별 주소

| 메뉴 | 주소 | 역할 |
| --- | --- | --- |
| 대시보드 | `/` | 실제 오늘 예정 경기와 Elo 승률·예측 근거, 예시 시즌 지표, 분석 페이지 진입 |
| 경기 일정 | `/pages/schedule.html` | 저장된 KBL 날짜별 일정·결과·쿼터별 점수와 CSV |
| 팀 > 팀관리 | `/pages/team-management.html` | 2026–2027 KBL 팀 성적·최근 5·10경기 차트와 기록, 2025–2026 예시 기록 |
| 리그 순위 | `/pages/standings.html` | 2026–2027 KBL 팀 순위·승패·최근 5경기 결과, 2025–2026 예시 순위 |
| 선수 기록 | `/pages/player-records.html` | 2026–2027 득점·리바운드·어시스트 평균의 부문별 리더, 출전 기록표. 2025–2026 예시 기록 |

## 디렉터리별 역할

```text
src/main/resources/static/
├─ index.html                    # 대시보드 요약 화면
├─ pages/                        # 메뉴별 독립 HTML
├─ css/
│  ├─ base.css                   # 색상·글꼴·공통 초기화
│  ├─ layout.css                 # 앱 셸·사이드바·반응형 배치
│  ├─ components.css             # 공통 버튼·카드·선택 필드·안내창
│  ├─ components/               # 지표·경기 프리뷰·차트·기록표·선수 카드
│  └─ pages/                    # 페이지별 배치와 전용 스타일
├─ js/
│  ├─ data/demo-data.js          # 예시 시즌 지표·경기·팀·선수 데이터
│  ├─ components/               # 공통 앱 셸·위젯·SVG 차트
│  ├─ state/preferences.js      # 공유 설정·URL 선택값 검증과 저장
│  ├─ utils/                    # 날짜·HTML·CSV 포맷과 내보내기
│  └─ pages/                    # 각 메뉴의 진입 모듈·렌더링·사용자 동작
└─ assets/
   ├─ icons/                    # 자체 제작 SVG 아이콘
   └─ illustrations/            # 자체 제작 코트 일러스트
```

## 실행

[로컬 MariaDB 실행 안내](../docker/README.md)에 따라 DB를 시작한 뒤 저장소 루트에서 Spring Boot를 `docker` 프로필로 실행합니다. 기본 접속 주소는 `http://localhost:9001/`입니다.

```powershell
.\gradlew.bat bootRun --args="--spring.profiles.active=docker --server.port=9001"
```

Python이 설치된 환경에서는 저장소 루트에서 아래 명령으로 DB 연결 없이 화면만 확인할 수도 있습니다.

```powershell
python -m http.server 5173 --bind 127.0.0.1 --directory src/main/resources/static
```

접속 주소는 `http://127.0.0.1:5173/`입니다. 종료는 `Ctrl+C`입니다. JavaScript ES 모듈과 루트 기준 자산 경로를 사용하므로 HTML을 `file://`로 직접 열지 말고 HTTP 서버에서 확인합니다.

Python 서버에서는 정적 레이아웃과 예시 데이터를 확인할 수 있습니다. 대시보드의 오늘 예정 경기, 경기 일정, 2026–2027 리그 순위·팀 성적·선수 기록을 확인할 때는 MariaDB와 Spring Boot를 실행합니다.

## 동작과 데이터 범위

- 공통 사이드바·상단 바·시즌 선택·안내창은 `components/app-shell.js`에서 한 번만 관리합니다.
- 페이지 정보와 메뉴 계층은 `components/ui.js`의 `PAGES`와 `NAVIGATION`에서 관리합니다. 팀 메뉴는 클릭으로 펼치거나 접고, 하위 팀관리 메뉴를 선택하면 독립 페이지로 이동합니다. 팀관리 페이지에서는 상위 메뉴가 자동으로 펼쳐집니다.
- 팀관리의 상단 경로는 `워크스페이스 / 팀 / 팀관리`입니다. 기존 팀 분석 화면을 재사용한 조회 UI이며, 팀 등록·수정·삭제나 DB 저장 기능은 아직 구현하지 않았습니다.
- 경기 일정은 선택한 날짜가 속한 주를 조회합니다. 경기 카드에서 1~4쿼터 점수와 최종 합계를 확인할 수 있습니다.
- 순위표의 팀 이름을 누르면 해당 시즌과 팀이 선택된 팀관리 화면이 열립니다.
- 선수 기록은 선택 지표에 따라 리더 카드와 전체 기록표를 함께 정렬합니다.
- 시즌·팀·경기 수·선수 지표 등은 `localStorage`로 페이지 간 공유합니다. 현재 페이지 선택값도 URL에 반영해 새로고침과 직접 접속을 지원합니다.
- 경기 일정은 선택한 날짜의 DB 기록을 CSV로 내보냅니다. 대시보드의 리포트는 예시입니다.
- 모든 페이지에 차콜·오렌지·우드 베이지 테마와 모바일 메뉴·키보드 탐색·동작 감소 설정을 공통 적용합니다.

### 오늘 예정 경기와 Elo

대시보드는 `GET /api/kbl/predictions/today`에서 한국시간 기준 날짜·시즌·경기 목록을 받아 표시합니다. 첫 경기를 기본으로 선택하며, 카드를 누르면 양 팀 예상 승률·Elo·예측 근거가 바뀝니다. 로딩, 남은 경기 없음, 예측 데이터 부족, 조회 실패를 구분하며, 실패 시 다시 조회할 수 있습니다. 차콜 배경과 오렌지 강조, 우드 베이지 보조 색상을 적용했습니다. [초기 승부예측 MVP](project-status.md#초기-승부예측-mvp)

대시보드의 시즌 지표와 CSV는 예시입니다. 경기 일정 화면은 기간별 경기 조회 API에서 경기 일정, 합계 및 쿼터 점수를 읽습니다. [기간별 경기 일정 조회](project-status.md#기간별-경기-일정-조회-api)

### 선수 기록

2026–2027 시즌에는 적재된 종료 경기의 실제 출전 수와 평균 득점·리바운드·어시스트를 표시합니다. 기준 지표를 바꾸면 상위 5명과 기록표가 함께 정렬됩니다. 이적 선수는 표 한 행의 출전 팀 열에 실제 출전한 팀을 모두 표시합니다. 조회 중·빈 결과·오류와 재조회 상태를 지원하며, 출전 여부 미확인 행이 있으면 그 수를 안내합니다. 2025–2026 시즌은 화면 검토용 예시 기록입니다. [시즌 선수 기록 조회 API](project-status.md#시즌-선수-기록-조회-api)

2026-11-27에 재시작한 개발 앱에서 적재 경기 74건과 선수 150명을 확인했습니다. 득점·리바운드·어시스트를 선택할 때마다 표 150행과 상위 5명 카드를 API 집계 순서와 대조했습니다. 390px에서 기록표 내부 스크롤, 팀관리 링크, 2025–2026 예시와 2026–2027 실데이터 간 전환을 확인했습니다. 빈 결과와 오류 후 재조회는 모의 응답으로 확인했습니다.

### 리그 순위

2026–2027 리그 순위에서 실제 DB의 선두 팀, 시즌 종료 경기 수, 참가 팀 수와 팀별 순위를 표시합니다. 최근 경기 결과는 오른쪽이 가장 최신이며, 적재된 종료 경기 결과가 없으면 `—`로 표시합니다. 조회 중 안내와 오류 후 재조회를 지원합니다. 2025–2026은 화면 검토용 예시 시즌입니다. [리그 순위 조회 API](project-status.md#리그-순위-조회-api)

### 팀관리

2026–2027은 팀 상세 조회 API에서 시즌 성적과 최근 5·10경기 결과를 읽습니다. 홈구장과 배지는 화면에 등록된 팀 정보를 사용합니다. 차트의 맨 오른쪽과 기록표의 첫 행이 각각 최신 경기입니다. 득점·실점이 모두 확인된 경기만 차트와 평균에 사용합니다. 조회 중에도 팀과 경기 수를 바꿀 수 있으며, 실패 시 다시 조회할 수 있습니다. 2025–2026은 화면 검토용 예시 시즌입니다. [팀 상세 조회 API](project-status.md#팀-상세-조회-api)

## 확인한 동작

- 메뉴별 독립 페이지 이동, 팀 하위 메뉴 펼침·접힘, 팀관리 선택 표시.
- 순위표에서 팀관리로 연결, 선택한 팀·시즌·최근 경기 수의 새로고침 유지.
- PC·모바일 메뉴와 키보드 닫기, 모바일 페이지의 가로 넘침 여부.
- 2026-11-26에 사용자가 대시보드 색상과 `0경기`·`오늘 남은 예정 경기가 없습니다.` 화면을 확인했습니다.
- 경기 선택, Elo·승률 표시, 기록 부족과 조회 실패 후 재조회는 모의 응답으로 확인했습니다. 실제 경기의 승률과 상세 화면은 정규리그 경기일에 검수합니다.
