# COURTSIDE 화면 구성

Spring Boot 정적 리소스로 제공하는 로컬 농구 분석 UI입니다. 별도의 프런트엔드 빌드 도구나 외부 CDN 없이 동작하며, 각 메뉴는 독립 HTML 페이지로 이동합니다.

최종 정리: 2026-10-26. 프로젝트 범위·예측 검토안은 [프로젝트 현황](project-status.md), 실제 API 항목·샘플·검증 결과는 [KBL API 데이터 정리](kbl-api-data.md)를 참고합니다. API 조회 검증은 화면의 실제 데이터 연동 완료를 뜻하지 않습니다.

## 메뉴별 주소

| 메뉴 | 주소 | 역할 |
| --- | --- | --- |
| 대시보드 | `/` | 핵심 지표·경기 요약·분석 페이지 진입 |
| 경기 일정 | `/pages/schedule.html` | 날짜별 일정·결과·선택 경기 프리뷰 |
| 팀 > 팀관리 | `/pages/team-management.html` | 선택 팀의 정보·차트·시즌 성적·최근 경기 기록 |
| 리그 순위 | `/pages/standings.html` | 전체 팀 순위·승패·최근 경기 결과 |
| 선수 기록 | `/pages/player-records.html` | 지표별 상위 선수·전체 예시 선수 기록 |

## 디렉터리별 역할

```text
src/main/resources/static/
├─ index.html                    # 대시보드 요약 화면
├─ pages/                        # 메뉴별 독립 HTML
├─ css/
│  ├─ base.css                   # 색상·글꼴·공통 초기화
│  ├─ layout.css                 # 앱 셸·사이드바·반응형 배치
│  ├─ components.css             # 공통 버튼·카드·선택 필드·안내창
│  ├─ components/               # 지표·경기 프리뷰·차트·기록표·선수 카드
│  └─ pages/                    # 페이지별 배치와 전용 스타일
├─ js/
│  ├─ data/demo-data.js          # 전체 페이지에서 사용하는 예시 데이터
│  ├─ components/               # 공통 앱 셸·위젯·SVG 차트
│  ├─ state/preferences.js      # 공유 설정·URL 선택값 검증과 저장
│  ├─ utils/                    # 날짜·HTML·CSV 포맷과 내보내기
│  └─ pages/                    # 각 메뉴의 진입 모듈·렌더링·사용자 동작
└─ assets/
   ├─ icons/                    # 자체 제작 SVG 아이콘
   └─ illustrations/            # 자체 제작 코트 일러스트
```

## 실행

기존 DB 환경변수를 설정하고 Spring Boot를 실행한 뒤 `http://localhost:9000/`에 접속합니다.

```powershell
.\gradlew.bat bootRun
```

Python이 설치된 환경에서는 저장소 루트에서 아래 명령으로 DB 연결 없이 화면만 확인할 수도 있습니다.

```powershell
python -m http.server 5173 --bind 127.0.0.1 --directory src/main/resources/static
```

접속 주소는 `http://127.0.0.1:5173/`입니다. 종료는 `Ctrl+C`입니다. JavaScript ES 모듈과 루트 기준 자산 경로를 사용하므로 HTML을 `file://`로 직접 열지 말고 HTTP 서버에서 확인합니다.

## 동작과 데이터 범위

- 공통 사이드바·상단 바·시즌 선택·안내창은 `components/app-shell.js`에서 한 번만 관리합니다.
- 페이지 정보와 메뉴 계층은 `components/ui.js`의 `PAGES`와 `NAVIGATION`에서 관리합니다. 팀 메뉴는 클릭으로 펼치거나 접고, 하위 팀관리 메뉴를 선택하면 독립 페이지로 이동합니다. 팀관리 페이지에서는 상위 메뉴가 자동으로 펼쳐집니다.
- 팀관리의 상단 경로는 `워크스페이스 / 팀 / 팀관리`입니다. 기존 팀 분석 화면을 재사용한 조회 UI이며, 팀 등록·수정·삭제나 DB 저장 기능은 아직 구현하지 않았습니다.
- 경기 일정은 예시 데이터가 있는 일주일 범위에서 날짜와 프리뷰를 선택합니다.
- 순위표의 팀 이름과 경기 프리뷰의 홈팀 정보 링크는 `?team=db&season=2026-2027` 형태로 팀관리 화면에 선택값을 전달합니다.
- 팀관리는 최근 5·10경기 차트와 경기별 기록을 제공합니다.
- 선수 기록은 선택 지표에 따라 리더 카드와 전체 기록표를 함께 정렬합니다.
- 시즌·팀·경기 수·선수 지표 등은 `localStorage`로 페이지 간 공유합니다. 현재 페이지 선택값도 URL에 반영해 새로고침과 직접 접속을 지원합니다.
- 대시보드와 경기 일정은 선택 날짜의 예시 경기 리포트를 CSV로 내보냅니다.
- 모든 페이지에 모바일 메뉴·키보드 탐색·동작 감소 설정을 공통 적용합니다.

일정·팀·선수 기록·예측 확률·적중률은 모두 UI 검토용 예시입니다. 실제 KBL 수집 API와 예측 모델은 연결하지 않았습니다. 수집 연동 시 데이터 모듈을 실제 응답의 화면 모델로 교체하고, 과거 예측에 미래 기록이 섞이지 않도록 기준 시점을 구분해야 합니다.

## 확인한 동작

- 메뉴별 독립 페이지 이동, 팀 하위 메뉴 펼침·접힘, 팀관리 선택 표시.
- 순위표에서 팀관리로 연결, 선택한 팀·시즌·최근 경기 수의 새로고침 유지.
- PC·모바일 메뉴와 키보드 닫기, 모바일 페이지의 가로 넘침 여부.
- 최근 메뉴 변경 후 브라우저 콘솔 오류와 누락된 파일 참조가 없는 것을 확인했습니다. Gradle 빌드·자동 테스트는 실행하지 않았습니다.
