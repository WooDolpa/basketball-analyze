# KBL API 데이터 항목과 검증 결과

검증 기준일: **2026-10-26**. [프로젝트 현황](project-status.md)과 [화면 안내](dashboard-ui.md)를 함께 참고합니다.

공식 사이트가 사용하는 조회 API를 실제로 요청해 제공 항목을 확인했습니다. 외부 개발자에게 안정성을 보장하는 API 계약을 확인한 것은 아니며, 아직 애플리케이션 수집기·DB·화면에 연결하지 않았습니다. 아래 수치와 예시는 당시 응답의 스냅샷입니다.

## 조회 서버와 요청 조건

| 서버 | 확인한 역할 |
| --- | --- |
| `https://api.kbl.or.kr` | 팀·선수 목록, 시즌, 순위, 경기·선수·팀 기록, 슛 차트 |
| `https://kbl-api.sports2i.com/api/v1` | 선수 등록 명단, 상세 프로필, 평균·시즌별·개인 최다 기록 |
| `https://api-stats.kbl.or.kr` | 시즌 팀 기본·고급·기타 득점·상대팀 기록 |

조사한 조회 경로는 로그인·인증 토큰 없이 응답했습니다. `api.kbl.or.kr`는 아래 헤더를 사용했습니다. 다른 서버에 같은 헤더가 모두 필수라고 확인한 것은 아닙니다.

```http
Channel: WEB
TeamCode: XX
lang: ko
X-Requested-With: XMLHttpRequest
Referer: https://www.kbl.or.kr/
```

Sports2i 선수 목록은 사용하지 않는 빈 필터를 보내지 않고 생략해야 합니다. `teamCd=&posSc=&flagCd=&playerNm=`를 명시했을 때 400이 반환됐고, `regSc=Y&pageNo=1&listCn=20`은 성공했습니다. 두 선수 목록 API의 필드명도 서로 다르므로 응답을 그대로 엔티티로 쓰지 않습니다.

## 시즌 범위

| 시즌 | 시즌 코드 | 정규리그 키 | 선수 기록 인원 | 프로필·해당 시즌 평균 | 팀 기본·고급 통계 |
| --- | --- | --- | ---: | --- | --- |
| 2022–2023 | `41` | `S41G01` | 199 | 199/199 성공 | 각 10개 구단 성공 |
| 2023–2024 | `43` | `S43G01` | 200 | 200/200 성공 | 각 10개 구단 성공 |
| 2024–2025 | `45` | `S45G01` | 204 | 204/204 성공 | 각 10개 구단 성공 |
| 2025–2026 | `47` | `S47G01` | 201 | 201/201 성공 | 각 10개 구단 성공 |
| 2026–2027 진행 중 | `49` | `S49G01` | 139 | 139/139 성공 | 각 10개 구단 성공 |

943개 선수·시즌 조합, 고유 선수 367명을 확인했습니다. 현재 등록선수 187명 중 이번 시즌 기록에 없는 49명도 프로필을 보완 조회했습니다. 이 중 45명은 과거 시즌 기록과 겹치고, 안세준·우상현·조혁재·지용현 4명만 추가됩니다. 최종 고유 대상은 **371명**, 프로필 조회는 총 **992개 조합**이며 HTTP 오류·빈 프로필·선수 코드 불일치는 0건입니다.

이 인원은 시즌 기록 응답 기준이며 출전시간 0인 행도 포함합니다. 과거에 등록만 되고 기록에 등장하지 않은 선수까지 모두 포함됐다고 보장하지 않습니다. 플레이오프·D리그·모든 개별 경기 기록·사진 파일의 존재는 이번 전수 검증 범위가 아닙니다.

## 주요 조회 경로

아래 경로는 표본에 사용한 실제 값입니다. 범용 수집기는 시즌·선수·팀·경기 코드를 인자로 받아야 합니다.

### KBL 기본·경기 API

| 용도 | 경로 (`https://api.kbl.or.kr` 기준) |
| --- | --- |
| 시즌 목록 | `/season/list` |
| 팀 목록 | `/common/teamList?kblYn=N&sangumuYn=N` |
| 기존 선수 목록 | `/players` |
| 시즌 순위 | `/league/rank/S49G01` |
| 순위 추이 | `/league/rank/S49G01/team-tracks` |
| 날짜별 일정 | `/match/list?fromDate=20261019&toDate=20261019&tcodeList=all&seasonCategory=R&seasonGrade=1` |
| 경기 정보·쿼터 득점·코치·관중 | `/match/S49G01N29` |
| 경기 선수 기록 | `/match/S49G01N29/player-stat` |
| 경기 팀 기록 | `/match/S49G01N29/team-record` |
| 슛 차트 등 | `/match/S49G01N29/match-chart` |
| 구단별 시즌 선수 기록 | `/leagues/S49G01/stats/players?tcodeList=16` |

### 선수 상세 API

| 용도 | 경로 (`https://kbl-api.sports2i.com/api/v1` 기준) |
| --- | --- |
| 현재 등록선수 | `/players?regSc=Y&pageNo=1&listCn=20` |
| 과거 포함 목록 | `/players?pageNo=1&listCn=20` |
| 프로필·요청 시즌 평균 | `/players/profile/49/291001` |
| 부문별 평균 | `/players/categories/avg/41/290407` |
| 선수별 시즌 기록 | `/players/categories/season/291001` |
| 한 경기 최다 | `/players/categories/mostgame/49/291001` |

경기별 상세 API는 `/players/categories/game/{정규시즌코드}/{D리그시즌코드}/{선수코드}` 형식입니다. 표본 `/players/categories/game/41/40/290407`에서 정규리그 54경기가 반환됐습니다. 이때 D리그 코드 `40`은 2021–2022 D리그이므로 이 조합을 2022–2023 D리그까지 검증한 예시로 사용하지 않습니다. 시즌 코드는 `/code/codes/4`에서 각각 확인해야 합니다.

### 시즌 팀 통계 API

모두 `https://api-stats.kbl.or.kr` 기준입니다. `seasonCode=49`는 다른 검증 대상 시즌 코드로 변경할 수 있습니다.

| 용도 | 경로 |
| --- | --- |
| 기본 누적 기록 | `/api/records/team/general/traditional?seasonCode=49&gameCode=01` |
| 고급 기록 | `/api/records/team/general/advanced?seasonCode=49&gameCode=01` |
| Four Factors | `/api/records/team/general/four-factors?seasonCode=49&gameCode=01` |
| 기타 득점 | `/api/records/team/general/misc?seasonCode=49&gameCode=01` |
| 상대 기록 | `/api/records/team/general/opponent?seasonCode=49&gameCode=01` |

팀 통계 응답에는 구단 외 집계 행이 포함될 수 있습니다. 11행을 11개 구단으로 세지 않고 해당 시즌의 10개 구단 코드와 대조했습니다. `rankNo`를 리그 순위로 쓰지 않습니다. 샘플 DB는 팀 통계의 `rankNo=1`이지만 별도 리그 순위는 4위였습니다.

## 데이터 해석·저장 시 주의점

1. **최신 프로필과 과거 소속을 분리합니다.** 김선형(`290407`)의 시즌 `41` 프로필 요청은 평균 기록을 시즌 41로 반환하지만 인적 프로필은 시즌 49의 수원 KT(`06`)입니다. 당시 경기 기록의 서울 SK(`55`)와 혼동하지 않습니다.
2. **선수·팀 코드를 문자열로 보존합니다.** 수원 KT의 `06`처럼 앞자리 0이 있는 코드가 있습니다. 이름으로 조인하거나 동명이인을 자동 병합하지 않습니다.
3. **동일 개념의 필드명이 API마다 다릅니다.** 선수는 `pcode`/`playerNo`, 이름은 `pname`/`kName`/`kname` 등이 있습니다. 변환 계층과 원본 출처를 둡니다.
4. **야투와 2점 필드를 구분합니다.** 경기·선수 기록의 `fg`는 2점, `fgt`는 전체 야투입니다. 팀 traditional의 전체 야투는 `fdg`이며 `fg`는 2점입니다. 슈팅 성공률의 분모를 잘못 연결하지 않습니다.
5. **`startCount`는 단위를 확인해야 합니다.** 2024–2025 92행, 2026–2027 64행에서 `gameCount`보다 컸습니다. 예: 김선형 2024–2025 `gameCount=51`, `startCount=206`. 경기 단위 선발 횟수로 쓰거나 곧바로 오류라고 단정하지 않습니다.
6. **빈 값·0·미제공을 구분합니다.** 출전시간 0, 빈 프로필 배열, 드래프트 비대상, 국적 누락은 서로 다른 상태입니다. 프로필 조회 성공으로 사진 파일 존재나 모든 항목의 정확성을 보장하지 않습니다.
7. **집계 지표는 재계산과 대조가 필요합니다.** 고급 지표의 산식·구간·반올림을 확인합니다. 예시에서 API가 제공한 값을 임의로 고치지 않았습니다.
8. **예측 기준 시점을 보존합니다.** 시즌 종료 후 누적값이나 최신 소속을 과거 경기의 사전 정보로 사용하지 않습니다. 수집 시각·시즌·경기·원본 URL과 응답을 구분해 보관하는 설계가 필요합니다.

## 전체 목록 조사에서 발견한 한계

최근 5시즌으로 범위를 줄이기 전에 전체 목록도 조사했습니다. 아래는 당시 전체 범위의 결과이며 371명 검증 결과와 혼합하지 않습니다.

| 항목 | 결과 |
| --- | --- |
| 현재 등록 명단 | 187명, 중복 0, 전원 프로필 조회 성공 |
| 등록선수 국적·학교 결측 | 국적 7명, 출신학교 48명 |
| 기존 KBL `/players` | 1,497행, 고유 코드 1,405개, 중복 코드 92개 |
| Sports2i 과거 포함 목록 | 표시 총건수 2,062, 실제 1,454명 |
| 페이지 검증 | 20명씩 1~104페이지 조회; 73페이지 14명, 이후 빈 응답 |
| 구분별 교차 검증 | 국내 874 + 외국 558 + 아시아쿼터 22 = 같은 1,454명 |
| 반환된 1,454명 상세 | 전원 조회 성공 |
| 두 목록 등의 코드 합집합 | 1,612개 요청, 정상 프로필 1,571개, 빈 프로필 41개, HTTP 오류 0 |

표시 총건수 차이 608을 그대로 누락 선수 인원이라고 해석하지 않습니다. 기존 목록에만 있는 코드 158개 중 117개는 상세 조회가 가능했고 41개는 HTTP 200이지만 프로필이 비어 있었습니다.

현재 등록 명단만으로 시즌 전체 선수를 구성하면 교체·이탈 선수를 놓칠 수 있습니다. 이번 시즌 기록에는 현재 등록 명단에 없는 라숀 토마스(`291436`)가 있어, 현재 등록 187명과 시즌 기록의 합집합은 188명이었습니다. 명단에서 빠진 이유는 확인하지 않았습니다.
